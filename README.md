# MyKos

Aplikasi manajemen kamar kos berbasis Android (`com.alif.mykos`) dengan penyimpanan lokal terintegrasi dan antarmuka Soft UI Liquid Glass[cite: 1].

## Fitur Utama
- **Autentikasi & Manajemen Akun:** Login, registrasi dengan penyimpanan nama pengguna, reset password, edit nama profil, dan logout menggunakan Firebase Authentication[cite: 1].
- **Dashboard Beranda Real-Time:** Menampilkan statistik *Total Kamar*, *Terisi*, *Kosong*, serta estimasi pemasukan bulanan, dilengkapi pencarian nomor kamar/penghuni, filter status (*Semua*, *Terisi*, *Kosong*), dan pengurutan data[cite: 1].
- **Manajemen Kamar (CRUD & Media):** Tambah, lihat detail, edit, dan hapus data kamar serta penghuni berbasis Room Database, termasuk pemilihan fasilitas, *DatePicker* tanggal masuk, dan unggah foto dari Kamera atau Galeri[cite: 1].
- **Komunikasi & Ekspor PDF:** Hubungi penghuni langsung melalui WhatsApp atau Telepon, serta ekspor data kamar terisi maupun detail satu kamar ke file PDF (termasuk berbagi file PDF ke penghuni)[cite: 1].
- **Tema & Notifikasi Pengingat:** Pengaturan mode tampilan (*Ikuti Sistem*, *Mode Terang*, *Mode Gelap*) dan notifikasi pengingat jatuh tempo sewa serta aktivitas penambahan kamar[cite: 1].
